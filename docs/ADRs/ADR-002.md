# ADR-002: Swedish as the default language

- **Status:** Accepted
- **Date:** 2026-11-15
- **Amends:** [ADR-001](ADR-001.md) (where the generated Swedish pages live)

## Context

ADR-001 placed the English pages at the site root and generated Swedish pages into `sv/`. Swedish is now required as the default language of the site: the subject, the sources and most of the audience are Swedish, so the main address should show Swedish.

## Alternatives

### A. Swedish at the root, English under `en/`

The English source pages move to `en/` and are served from there unchanged. The builder generates the Swedish pages at the root from `en/` and `i18n/sv/`.

- **Pros:** the main address, shared links and search results are Swedish, also without JavaScript; one clean URL per language; the translation files and builder are reused.
- **Cons:** the root HTML becomes generated output; English URLs move from the root to `en/`.

### B. Root index redirects to `sv/`

The English root stays and `index.html` redirects to `sv/index.html`.

- **Pros:** minimal change; English structure untouched.
- **Cons:** only the home page defaults to Swedish; every other root URL stays English; the redirect is visible in the address bar.

### C. JavaScript redirect for first-time visitors

English pages detect visitors without a stored choice and redirect them to the Swedish counterpart.

- **Pros:** no URL changes; a stored choice is respected.
- **Cons:** search engines and visitors without JavaScript see English; a flash of English before the redirect; the default is a client-side trick rather than the site's structure.

## Decision

Alternative A. English source pages live in `en/`. `node tools/build-sv.mjs` writes the Swedish pages to the root, using `relocateLinks` in `tools/i18n.mjs` to resolve every relative link from `en/<page>` to `<page>` and to map page links to the Swedish tree. Both trees carry `hreflang` links, with `x-default` pointing to Swedish.

The language switch shows flags with the language codes, Swedish first, and links to the same page in the other language.

## Consequences

- Edit English pages in `en/` only; the root HTML pages are generated and are never edited by hand.
- After an edit: `node tools/build-sv.mjs --extract`, translate the new entries in `i18n/sv/`, then `node tools/build-sv.mjs`.
- `scripts/main.js` treats the root as the Swedish page root and `en/` as the English one.
- Old links to English root pages now open the Swedish version of the same page; the switch leads to English.
