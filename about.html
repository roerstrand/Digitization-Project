About this project

This project emerged from an interest in the cultural history of the Malmö region and in the Jugend architectural style — the last major expression of which in Sweden is represented by the Baltic Exhibition of 1914.

Robin Strandberg designed and built this website, carried out archival research at two institutions (Malmö City Library and Malmö City Archive), executed the scanning sessions, processed all images, authored the Dublin Core metadata records across the full collection, performed copyright analysis under Swedish law, and conducted quality assurance. My Lundborg contributed TEI XML encoding and XSL stylesheet authoring for the commissariat texts; scanning sessions at Malmö City Library were a joint effort.

The project reviewed 7 source volumes, produced a described collection spanning 4 national pavilions, and documented each item with a 15-element Dublin Core metadata record — published openly in a public GitHub repository under a Creative Commons licence.

This website — responsive layout, dark mode, custom JavaScript lightbox, mobile navigation, and all CSS — was hand-coded from scratch without any framework or CMS. The site is itself a technical artifact, not only a presentation layer.

The domain is cultural heritage archives. The methods — structured metadata, rights clearance, end-to-end digital delivery, and open data publishing — are transferable to any organisation managing unstructured information assets: municipal archives, corporate knowledge bases, library collections, or AI training datasets.

Project Purpose

Preservation and Access

The primary motive was preservation: the physical sources — century-old catalogs, photo albums, and blueprint books — are fragile, irreplaceable, and at risk of being deaccessioned. Digitization reduces wear on the originals and ensures the material survives in a form that can be freely shared.

A secondary motive was access. By building a contextualised website rather than simply uploading raw scans, the project creates an entry point for anyone curious about the Jugend architectural style, the Baltic Exhibition, or pre-war European exhibition culture — not only archivists or specialists.

Source Institutions

Malmö City Library & City Archive

The core printed material — exhibition catalogs, official view albums, postcards, and commissariat brochures — was sourced from Malmö City Library, which holds a dedicated shelf of Baltic Exhibition publications classified under Bhz Baltic Exhibition 1914. A staff member responsible for older collections supported the project by presenting available titles and arranging scanning access.

Supplementary documentary material, including more detailed blueprints and contemporary newspaper clippings, was gathered at Malmö City Archive, where documents were photographed on-site for contextual reference.

Scanning

Equipment and Resolution Strategy

Scanning was carried out at Malmö City Library on an Epson Perfection V600 Photo scanner using 24-bit colour. Two resolutions were chosen deliberately:

300 dpi for photographs and images — sufficient for display quality and viewer experience without generating prohibitively large files. 600 dpi for text documents and blueprints — higher resolution enables legibility when zoomed in and keeps the material suitable for future OCR processing without requiring a return visit to the physical source.

A white A4 sheet was used as a reference background during scanning. All images were subsequently processed in GIMP: straightened, cropped, and embedded with descriptive metadata before being committed to the repository.

Metadata

Dublin Core and Embedded Image Metadata

Each digitized object in the collection carries structured metadata aligned with the Dublin Core standard — a widely adopted, interoperable schema for describing cultural heritage resources. Metadata fields include title, creator, subject, description, publisher, date, type, format, identifier, source, language, relation, coverage, and rights.

Metadata was initially catalogued collaboratively in a shared Google Drive spreadsheet before being embedded directly into image files via GIMP and documented on the per-building metadata pages accessible from each building page on this site.

TEI (Text Encoding Initiative) XML was used to encode the commissariat texts, with XSL stylesheets transforming the TEI source into XHTML files for each participating nation.

The full metadata schema and encoding decisions are documented on the Methodology page.

Information Structure

GitHub, TEI, HTML/CSS/JS

The project's full collection lives in a public GitHub repository, making every image, metadata record, TEI file, and stylesheet available for inspection, download, and reuse under a Creative Commons licence. GitHub also served as the collaboration platform throughout the project, enabling distributed work despite the team working remotely.

The website — built entirely in HTML, CSS, and JavaScript — acts as the pedagogical layer: it contextualises the digitized material with historical background, presents images in a slideshow gallery, and links each building to its metadata record. No framework or CMS was used; the codebase is hand-authored and lightweight.

Visual Studio Code was the primary editor; oXygen was used for TEI and XSL work due to its built-in XML validation and real-time XSLT transformation support.

Web Publication

Open Access via GitHub Pages

The site is hosted on GitHub Pages — a zero-cost static hosting solution appropriate for an open-source project. Choosing GitHub as both repository and hosting platform ensures full transparency: visitors can inspect the source, fork the repository, or report issues directly.

Before publishing, copyright was carefully verified. The digitized catalogs were published in 1914 by Förlags-aktiebolaget i Malmö. Under Swedish copyright law (1960:729, §44), works whose copyright is held by a publisher enter the public domain 70 years after creation — placing all material well outside protection. The one named photographer, Fred Riise (Danish), died in 1933, also past the 70-year threshold.

Source Material

What Was Digitized

Seven printed sources held at Malmö City Library were reviewed in person; a subset was selected for digitization. These included official exhibition catalogs, postcard albums, photographic view albums, the official general catalogue with floor plans, and a Danish commissariat publication authored by photographer Fred Riise.

In total, the collection covers images of all four selected buildings across multiple source types: catalog illustrations, exterior photographs, interior photographs, construction-site photographs, and architectural floor-plan blueprints. Surrogate numbering (e.g. 2:4 = Book 2, page 4) preserves a direct link between each digital file and its physical source.

Challenges

Scope, Workflow, and What Was Learned

The project's widest challenge was scope management: the Baltic Exhibition is a large topic, and material was abundant. Limiting the focus to four buildings — and within those, to architectural images — required ongoing selection decisions at every stage.

Working with GitHub for the first time introduced merge conflicts and versioning friction. A known GitHub metadata bug prevented full metadata embedding on two commissariat images; these are documented exceptions in the collection.

The process combined what Dahlström (2011) terms mass digitization in the early scanning phase — capturing broadly so material could be reviewed remotely — with critical digitization in the selection and encoding phase, where manual judgment and rich metadata replaced automated throughput. This hybrid reflects the realities of a small-team, limited-budget project and was itself a significant learning outcome.

For a frank account of what worked, what didn't, and what we'd do differently, see the Reflections page.
