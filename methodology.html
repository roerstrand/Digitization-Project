Overview

From Archive to Web

Displaying historical images is straightforward. Making them searchable, traceable, and reusable by others is not. This page documents the decisions behind the digitization workflow: what was recorded, why those fields were chosen, and how the metadata is embedded into the site so that both humans and machines can read it.

The source material consists of printed exhibition catalogs and photographic records from the 1914 Baltic Exhibition, held at Malmö City Library under shelf mark Bhz Baltiska utställningen. All scanning took place on 20 May 2023.

Digitization

Equipment & Capture

All images were captured using a flatbed scanner rather than a camera to ensure even illumination, no perspective distortion, and consistent resolution across the collection. The source documents are printed catalogs — opaque, non-transparent media — which flatbed scanning handles reliably.

Metadata Schema

What Was Recorded and Why

Each digitized object is described by a consistent set of fields aligned with the Dublin Core standard — a widely adopted, interoperable schema for describing cultural heritage resources. The schema covers provenance (where the original came from), technical capture conditions (how it was digitized), intellectual content (what the image shows), and rights (who may use it and under what terms). Together these fields allow an item to be understood and re-used independently of this website.

Metadata was initially catalogued in a shared spreadsheet during the project, then embedded directly into the image files via GIMP and documented on the per-building metadata pages on this site.

Field Purpose
Original Source Names the holding institution and shelf mark — the chain of custody from physical to digital.
Building / Architect Subject description, enabling filtering by structure or creator.

Geographic Origin Hierarchical location (city → region → country → continent) for geographic indexing.

License The explicit terms under which the digital surrogates are released to the public.
TEI Encoding

Structured Text with TEI/XML

The written catalog texts — the commissariat lists naming each country's delegates — were encoded in TEI (Text Encoding Initiative), an XML-based standard for representing historical and literary documents in a machine-readable form. TEI is the international standard used by archives, libraries, and digital humanities projects to encode text in a way that separates content from presentation.

An XSL stylesheet was then used to transform the TEI/XML source into the HTML pages served on this site. This separation means the underlying data remains clean and standards-compliant regardless of how it is displayed — the same TEI source could equally be transformed into a PDF, a dataset, or ingested by a library catalogue system.

Encoding Standard Text Encoding Initiative (TEI P5)
Format XML with XSL transformation to HTML
Documents Encoded Commissariat lists for Germany, Denmark, Russia, and the construction committee
Why TEI Institution-grade interoperability; separates data from display; enables re-use in library systems
Web Discoverability

Metadata Embedded in the Page

Every image on this site carries its descriptive metadata directly in the HTML as data-* attributes. This means the metadata travels with the image element — it is not stored in a separate database that could go offline or become decoupled from the content.

Each image records its caption, document type, source reference, year, and collection. This structure allows the metadata to be read by JavaScript (for the caption overlay), by search engines, and by anyone inspecting the page source.

Example — image element attributes data-caption — descriptive caption for the image
data-doctype — document type (e.g. Photograph)
data-docsource — catalog volume and page reference
data-year — year of the depicted event
data-collection — holding institution
Copyright & Licensing

Legal Framework

The original photographs and catalog illustrations date from 1914 and are in the public domain under Swedish copyright law. The applicable provisions are Lag (1960:729) §§ 7 and 44, which govern the expiry of copyright for photographic works and other published material.

The digital surrogates produced for this project are released under Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International (CC BY–NC–SA 4.0). This means anyone may share and adapt the material for non-commercial purposes, provided they give attribution and apply the same license to any derivative work.

For questions about specific image-to-source correspondence, open an issue on the project repository on GitHub. Source volumes were held at Malmö City Library under shelf mark Bhz Baltiska utställningen at the time of digitization.
